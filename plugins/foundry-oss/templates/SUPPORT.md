## What we need in a bug report

Version and how you installed it · runtime and OS versions · the exact command or minimal code ·
what happened, verbatim · what you expected and why · the last version that worked.

Reports missing these get one comment asking for up to three specific things. If there is no
reply for {{NEEDS_INFO_DAYS}} days we close them — reopening is free and welcome.
