title: GitHub Actions are pinned by commit SHA, never by moving tag
tags: [ci, security]
confidence: high
source: code
created: 2026-08-27
expires: null
supersedes: null

**Why:** a tag can be repointed by whoever controls the action repository, which is a supply-chain hole in every workflow that trusts it.
**How to apply:** resolve the SHA with gh api repos/<owner>/<repo>/git/ref/tags/<tag> and keep the version in a trailing comment so Dependabot can update both.
