enforcement: warn softens the Bash rules from deny to ask, and nothing else. stop-verify and subagent-firewall are governed by verifyOnStop and handoffSummaryTokenBudget; only enforcement: off switches them off.

**Why:** the first implementation gated both on enforcement === "gate", so a project setting verifyOnStop: true alongside warn silently got no verification at all. A configuration that reports a gate as on while the gate does nothing is worse than no gate, because it is trusted. Any future level added here must keep every gate either doing what its own setting says, or visibly off.
